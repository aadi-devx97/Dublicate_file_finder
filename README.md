# 🔍 Duplicate File Finder (Python Automation Tool)

A Python automation tool that scans folders to detect duplicate files using file hashing.  
The program can also optionally remove duplicate files to help clean storage.

## 🚀 Features

- Scans any folder for duplicate files
- Uses hashing to accurately detect identical files
- Displays duplicate file pairs
- Optional automatic deletion of duplicates
- Simple command-line interface

## 🛠 How to Run

1. Clone the repository
2. Open the project folder
3. Run:

python main.py

4. Enter the folder path you want to scan

## 📂 Example Output

Duplicate files found:
copy_file1.txt is duplicate of file1.txt

Do you want to delete duplicate files? (yes/no)

- File handling
- Hashing (hashlib)
- OS file system operations
